# CampusMate · 校园跑腿互助平台 Demo

一个使用原生 HTML、CSS 和 JavaScript 构建的静态网站演示项目。无需安装依赖或启动后端，可直接在浏览器中运行，也适合部署到 GitHub Pages。

## 本地运行

1. 解压项目文件夹。
2. 使用 VS Code 打开 `CampusMate` 文件夹。
3. 直接用浏览器打开 `index.html`，或安装 VS Code 的 Live Server 扩展后右键 `index.html` → **Open with Live Server**。

## 页面与功能

- 首页概览：平台数据、任务分类、最新任务、信用概览。
- 任务大厅：按分类筛选、关键词搜索、查看任务详情。
- 发布任务：提交任务后立即出现在任务大厅。
- 接单与完成：支持接单、每周最多接单 5 次、完成任务后更新互助记录和信用分。
- 我的互助：查看我帮助过谁、谁帮助过我和进行中的任务。
- 个人中心：编辑资料、模拟校园身份认证、查看接单额度、成长打卡、重置演示数据。
- 互助公约：查看平台倡导的互助规则。

## 数据与真实性说明

演示操作保存在当前浏览器的 `localStorage` 中。清除浏览器站点数据或点击“重置演示数据”会恢复初始数据。

校园身份、信用分、积分与平台统计均为模拟数据。项目不连接学校身份系统、不涉及真实支付，也没有后端权限或跨设备同步。

## 部署到 GitHub Pages

将 `index.html`、`style.css`、`script.js` 和 `README.md` 上传至 GitHub 仓库根目录，然后在仓库的 **Settings → Pages** 中选择从 `main` 分支的根目录发布。
